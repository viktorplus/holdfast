## Как читать команды

У каждого блока команд написано, где он выполняется:

- **на сервере** — в SSH-сессии, от `root`;
- **у себя** — на вашем компьютере, где хранится ключ шифрования.

Заглавные слова в командах (`ВАШ_СЕРВЕР`, `ИМЯ_ТОМА`) нужно заменить своими.
В примерах приложение называется `myapp`: папка проекта `/root/myapp`,
контейнер базы `myapp-db-1`, контейнер сайта `myapp-wordpress-1`, машина
подписывается как `web-1`.

## Три вещи, без которых копия бесполезна

1. **Ключ шифрования лежит не на сервере.** На сервере только публичная часть;
   расшифровать копию сервер не может. Потеряете приватный ключ — копии не
   открыть, восстановить его нельзя. Хранить в двух местах.
2. **Имя машины (`host-label`) нужно помнить.** При восстановлении на новом
   сервере его нужно указать то же самое, иначе holdfast откажется
   (подробности в [04-restore.md](04-restore.md)).
3. **Копия, которую не пробовали восстановить, — это надежда.** Репетиция
   описана в [04-restore.md](04-restore.md#проверка-копии-без-риска).
